commands. The pinned image ID and sky130 library preflight passed. The first

remain pending until the repaired flow completes.

-no_clocks` form is supported and retains the same 1 ns input delay for each
non-clock input; reset remains a false path. The runner now invokes `sta
-no_init -exit` so any future Tcl error fails promptly instead of waiting at
the prompt. The first timing script is being rechecked before a full retry.
