`flow/run_flow.py` script is designed to synthesize and time each variant with
the same sky130_fd_sc_hd library and SDC constraints. It rejects observation
signals in the mapped netlist, records Yosys/OpenSTA versions and all tested
clock periods, and writes one raw result per variant/repeat. `flow/parse_results.py`
will refuse missing or inconsistent author outputs, then generate the area,
Fmax, and critical-path table with provenance. Exact author commands are in
`flow/README.md`.

No physical area, delay, or Fmax value has been measured. The acceptance check
remains pending until the author's real outputs have been parsed.
