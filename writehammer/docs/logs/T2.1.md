# T2.1 mem_model

- **Goal:** simulation-only memory model: configurable latency, ready/valid interface, loaded from the hex, a simple arbiter with D$ priority. Accept: unit test for latency and ordering.
- **Done:** `rtl/mem_model.sv`: one unified 256 KiB array (word count is a parameter) behind two ports (I$ read-only, D$ with line writes and byte enables), one request in flight, D$ priority, non-preemptive; fixed or seeded-random latency (uniform 1..2L-1); line size 16/32/64 bytes; zero-filled then `$readmemh`. `tb/tb_mem_model.sv`, `tests/mem_model_test.py`, `tests/mutants/mem_mutants.py` (6 mutants). The old two-memory `backing_mem` was removed (DEC-004).
- **Interface:** `valid` held until `done`; `ready` pulses at acceptance; `done` is a one-cycle pulse L cycles after acceptance; writes take effect at the edge ending the done cycle. This keeps the earlier `backing_mem` timing.
- **Results:** `tests/mem_model_test.py` 18/18: LINE_BYTES 16/32/64 x LATENCY 1/2/3/10 fixed, plus random latency (LATENCY 5 and 10, two seeds) with a determinism check (same seed, same sequence) and a seed-dependence check. Checks: exact latency, line packing, byte-enable writes, read-after-write, D$ priority and the I$ served right after, done is a one-cycle pulse, INIT_FILE words at address 0 and zero fill past the image. All 6 mutants caught (off-by-one latency, swapped priority, ignored byte enables, reversed lanes, unbounded random latency, writes lost).
- **Problems:** two testbench bugs, both the same SystemVerilog trap: a variable declared with an initializer inside a loop or block is initialized once at time 0 (`logic [31:0] exp = ...` stayed at its first value; `orig = rd` captured `x`). The DUT output was right both times (checked by reading the output). Fixed by assigning procedurally.
- **Deviations:** none.
