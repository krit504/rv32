# T1.2 Encoder, reference model, directed tests and mutants for the sub-word ops

- **Goal:** encoder and reference model for the six instructions; directed tests (each instruction at every legal offset, sign extension, adjacent sub-word stores, forwarding a loaded sub-word, load-use stall); a mutant each for wrong sign extension, wrong byte lane, byte enable stuck.
- **Done:**
  - `tests/asm.py`: encoders for the six instructions plus the remaining ALU and branch encoders (CHG-003).
  - `tests/refmodel.py`: an independent RV32I instruction-set simulator written from the ISA spec; `tests/refmodel_selftest.py` checks it against hand-computed values with the derivation on each line.
  - `tests/subword_tests.py`: 11 directed tests, RTL vs model, on all 31 registers and the first four data words, caches off and on at LAT 1, 2, 3, 10 (55 runs).
  - `tests/mutants/subword_mutants.py`: S1 lb zero-extends, S2 wrong byte lane, S3 `sb` enable stuck (the three required), plus S4 `lh` zero-extends, S5 `sh` enable stuck, S6 `sb` data not replicated, S7 `lbu` sign-extends, S8 `funct3` not carried.
  - `make test-subword`; `run_mutants.py` runs the sub-word tests against every mutant (CHG-002).
- **Results:** `make test`: subword 11/11 in all five configurations; mutants 20/20 caught (12 earlier + 8 new); every S mutant is caught by `subword_c0` (a sub-word test, so each fails for the intended reason). Total mutants: 20 caught, 1 argued equivalent.
- **Problems:**
  - Symptom: with caches off, 10 of 11 tests failed on `mem[i]=xxxxxxxx expected 0x0`. Root cause: `dmem` had no initialization, so untouched words read `x`, while the model and the cached path start at 0. Fix: DEC-007 (zero-initialize `dmem`). Regression: the same tests now pass, and the memory comparison covers words the program never wrote.
  - The refmodel self-test first failed on `jalr` target 17: my hand derivation said the skipped instructions were one, but target `16` is the final `jal`, which skips two. The model was right; corrected the expected value with the derivation. Expected values in the self-test are hand-derived from the ISA, never taken from model output.
- **Deviations:** none.
