## Correction (2026-11-05)
The line above that attributes D1 calibrated's 9.8 % restricted stores to `crc32` was wrong. This agrees with the T6 matrix (D1 `fp_cycle_frac` 0 on `crc32` at the primary setting). Found by a cross-check from the rationale notes.
