# T4.6 — mixed workloads

The middle phases use the author's group's RLA/RTA/RnLA/RnTA taxonomy from TENDRA and the Write Hammer draft (local papers cited in T4.2). Each mixed program has a benign array-update phase, one direct attack phase, and the same benign phase. PHASE markers 0, 1, 2, 3 bracket the phases; `perf_start`/`perf_stop` bracket the full sequence. The program checks the attack target and every benign array word before HALT.

`analysis/attack_mixed.py` builds each program natively and as RV32I, runs the cached core with latency 20, requires HALT 0, checks exact golden cache replay, then checks the three marker gaps against 1M cycles with a 1% tolerance. Its known-bad marker sequence and shortened phase controls must fail the checker. It generates `analysis/attack_mixed.csv` and its source-hash provenance sidecar. Run:

```sh
scripts/run.sh -- .venv/bin/python analysis/attack_mixed.py
```
