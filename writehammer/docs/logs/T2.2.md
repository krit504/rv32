# T2.2 Stall enables and the random stall-injection test

- **Goal:** stall enable on every pipeline register, integrated with the hazard unit, with the load-use / flush interaction documented. Accept: a random stall-injection test leaves every architectural result unchanged on the T1 suite.
- **Done:** the enables (`StallF` pc, `StallD` F/D, `StallE` D/E, `StallM` E/M, `StallW` M/W) and the hazard-unit equations already existed from the cache work (priority reset, hold, clear, capture; freeze holds every register including M/W so a held consumer keeps its forwarding source). New: top parameter `INJECT_STALL_SEED` (0 = no logic): two seeded LFSRs OR a pipeline-wide freeze into `dmiss` and a fetch bubble into `imiss` at about one cycle in four each. `tests/stall_injection_test.py`, `tests/mutants/stall_mutants.py` (4 mutants), `make test-stall`.
- **Interaction with load-use and flush (as built):** a freeze (`dmiss`) outranks everything: all five registers hold, and `FlushD`/`FlushE` have no effect while frozen, so a redirect or load-use stall is evaluated again after the freeze ends (the instruction that caused it is still in Execute). An I$ miss alone holds only `pc` and bubbles F/D (`StallF = 1, StallD = 0, FlushD = 1`), but if a load-use stall is active `F/D` must keep its instruction (`FlushD = imiss & ~stallCond`), and a redirect in the same cycle wins over the fetch stall (`StallF = ... imiss & ~redirectE`).
- **Results:** 1000 random hazard-dense programs for each of caches off and caches on (LAT 3) with injection seeds 3 and 11, all equal to the reference model (4000 runs); the 21-check no-hazard regression with injection, caches off and on; a control shows injection really stalls (41 cycles in the window without, 82 with); all 4 stall-enable mutants caught.
- **Problems:** the first caches-on no-hazard run with injection failed 20/21 (`x5 = 0x1410`, expected `0x1010`): the longer run let the PC run off the end of the 27-instruction program and wrap the 1 KiB memory, re-executing the program, so an `auipc` gave a second value. A test artifact (the old datasheet's Note 13): the test now appends `jal x0, 0` to the image so the cycle budget no longer matters.
- **Deviations:** none.
