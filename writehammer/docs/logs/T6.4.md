# T6.4 — sensitivity

`analysis/sensitivity.py` reads only the complete measured Section 7 CSV. It
plots benign false-positive cycle fraction against attack-phase detection
latency for D1, D2 and D3 across the registered windows, calibrated threshold
multipliers, modes, and D2 M values. For mixed workloads, the x-axis value
comes from that image's own benign phases. The derived CSV records detected
and censored seeds, plus mean and full range for detections; no invented
latency is assigned to an undetected phase.

The RLA/RTA/RnLA/RnTA taxonomy is prior work of the author's group (TENDRA
and the Write Hammer draft). The script writes SHA-256 provenance sidecars
for its CSV and figure.

Acceptance: `MPLCONFIGDIR=/tmp/wh-mpl scripts/run.sh -- .venv/bin/python analysis/sensitivity.py`
passed on 2026-11-05. It generated 1,064 measured detector/setting/attack
points from the complete 9,723-row matrix. The derived CSV records 2,466
censored attack seeds across those points; an undetected phase has an empty
latency, never a substitute number. `analysis/sensitivity.png` plots measured
false-positive cycle fractions against measured detection latencies, and both
artifacts carry data and script hashes in provenance sidecars.
