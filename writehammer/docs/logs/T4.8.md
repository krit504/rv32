# T4.8 — baseline T_fail table

The attack names are prior work of the author's group (TENDRA and the Write Hammer draft; local papers cited in T4.2). The table uses the spec's modeled endurance of 10^15 writes and the existing `analysis/wear_stats.py` extrapolation at 50, 100 and 500 MHz. These are modeled lifetimes, not measured hardware failures.

Command:

```sh
scripts/run.sh -- python3 analysis/attack_tfail.py analysis/wear_baseline_f3a7ccb0eb4d.csv
```

Result: `analysis/attack_tfail_baseline.csv` has one row for each of 13 benign and 24 attack workloads. `analysis/attack_tfail_baseline.csv.json` names the generator, the git commit, the benign CSV hash, every attack wear-summary hash, and the table hash. All attack summaries come from the final 24/24 exact-replay run of T4.7. No number was entered by hand. T4.7's separate PMR acceptance conflict remains unresolved.
