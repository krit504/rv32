# T2.4 D$

- **Goal:** direct-mapped D$, write-back + write-allocate, dirty bits, byte-enable stores, fill and dirty-eviction FSM, and the restricted-store path of Section 4 (write back if dirty, invalidate, write through). Accept: directed tests (hit, miss, eviction, dirty write-back, byte stores, conflict, restricted store with the line present clean, present dirty and absent).
- **Done:** `rtl/dcache.sv` (design and timing in its header): states LOOKUP, WB, FILL, BYP_WB, BYP_WR, WAIT_ST, WAIT_FILL; parameters `CACHE_BYTES`, `LINE_BYTES`, `DC_WRITE_LATENCY`, `NPEEK`. Store hits complete in the lookup cycle (no memory access); a store miss is fill then store hit (two array writes); a bypassed store never writes the array. Observation: array-write events (`aw_*`), per-request trace (`tr_*`), counters, coherent debug peek (the D$ overlaid on memory). `rtl/write_guard.sv` (NONE, ALWAYS) feeds the `bypass` input from the top. Byte enables and the lane logic from T1.1 are unchanged.
- **Tests:** `tests/dcache_test.py`: randomized operation lists (1500 operations per run) against two independent oracles, 51 configurations (1/2/4/8 KiB x 16/32/64 B x latency 1/3/10 plus random latency, array-write latency 1 and 4, bypass probability 0, 0.15, 0.5): a plain byte array (every load, and the whole final memory with the cache overlaid) and `tests/cache_model.py` (counters, per-line array-write counts, and the stall cycles of every request). The directed cases (every byte offset, sub-word merges, conflicts, store-then-load, bypass of present-dirty / present-clean / absent lines, back-to-back bypasses) are covered by the generator's hot-line and conflict addresses with bypass probabilities up to 0.5. Full-core: `tests/cache_integration.py`, `tests/random_lockstep.py` and `tests/invariant_test.py`.
- **Results:** 51/51. 12 D$ mutants all caught by `dcache_test.py`: dirty bit never set, dirty victims dropped, bypass leaves the line valid (clean and dirty paths), bypass writes the array, byte enables ignored, fill keeps the dirty bit, write-back to the wrong address, miss counter dead, bypass skips the write-back of a dirty line, refills after bypass not counted, wrong word returned.
- **Problems:**
  1. Header bug found by working through the state machine against the test's stall formula: a bypassed store completes in the memory's done cycle, so it costs L+1 (clean or absent) or 2L+2 (dirty), not L+2 and 2L+3 as I first wrote. The header and the model's `stall()` now agree with the RTL.
  2. Icarus ran this testbench at about 2k cycles/s (a full 51-configuration run took over 10 minutes); the test now runs under Verilator (`tests/vl_tb.py`), 2 m 20 s.
  3. A first version of the random-program lockstep failed 0/20 with caches on because of a generator bug (CHG-015), unrelated to the D$ but found by it.
- **Status:** DONE. Unit test 51/51 and 12/12 D$ mutants; the full `make test` passed after the last edits (rc=0); the invariant test (T2.6) also catches the D$ mutants D1, D2, D7, D11 once small caches are included.
