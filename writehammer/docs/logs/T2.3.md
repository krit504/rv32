# T2.3 I$

- **Goal:** direct-mapped, read-only I$, parameterized size and line size, line-fill FSM. Accept: directed tests (hit, miss, conflict, sequential fetch across lines).
- **Done:** `rtl/icache.sv`: `CACHE_BYTES` (default 2048) and `LINE_BYTES` (16/32/64) parameters, line-fill FSM `LOOKUP -> REFILL -> LOOKUP` with the miss index and tag captured at the miss (a branch can change PCF while a refill runs), `imiss` held through the whole refill including the `mem_done` cycle (cost L+2 cycles), counters (`refill_cnt`, lookups, misses, stall cycles). It uses the shared memory interface (`mem_valid` held until `mem_done`, line-aligned address, whole-line data) so it can sit behind the unified `mem_model` with the D$.
- **Tests (all run with the I$ in the full core, the I$ has no separate unit test):** `tests/cache_integration.py` (first-fetch pattern: L+2 misses, 4 hits, then misses again, at LAT 1, 2, 3, 10; loop that fits in the cache refills once; branch to an uncached block; imiss together with a load-use stall and with a taken branch), `tests/hazard_tests.py` and `tests/random_lockstep.py` with caches on, the arch tests and the benchmarks (all execute out of the I$).
- **Mutants caught:** C1 (valid not cleared at reset), C2 (refill under the live address), C7 (word lanes reversed), plus C3/C4 and the stall mutants which also break fetch behaviour.
- **Status:** DONE. The full `make test` passed after the last edits (rc=0, mutants 52/52 caught). Geometry is exercised in correctness tests too: `tests/invariant_test.py` runs three small geometries (1 KiB; 512 B with 32-byte lines; 256 B with 64-byte lines), and the T2.7 sweeps (`analysis/caches.py`) cover 1 to 8 KiB and 16 to 64-byte lines on 13 workloads.
