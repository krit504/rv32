# T3.2 Wear statistics

Goal: compute PMR over all and written lines, maximum and mean array-write counts, extrapolated lifetime at 50/100/500 MHz, and line and window plots.

Created `analysis/wear_stats.py`. It validates that window sums equal per-line totals, writes JSON and CSV summaries, and makes PNG figures with sidecar JSON containing the script, source CSV hashes, commit, and run-set ID. `T_fail` uses illustrative endurance 1e15 writes and measured simulation cycles; it is an extrapolation from a short run.

Acceptance command: `scripts/run.sh -- .venv/bin/python analysis/wear_stats.py work/wear_smoke/run`. Result: `work/wear_smoke/run/wear_summary.{json,csv}`, `wear_per_line.png`, `wear_heatmap.png`, and sidecars produced. Smoke values: 71 writes, `w_max=9`, PMR over all 128 lines 16.225352112676056. The first invocation used system `python3` and failed because matplotlib is only installed in `.venv`; rerunning with the documented environment passed.

No RTL or protected tests changed. Commit: this task's `T3.2:` commit on `t3-wear` (`git log --format=%H -1`).
