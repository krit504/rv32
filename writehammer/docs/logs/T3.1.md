# T3.1 Wear monitor

Goal: record every D$ data-array write by line and cycle window, phase markers, and completed D$ accesses.

Created `tb/wear_monitor.sv`, `tb/tb_wear.sv`, and `analysis/wear_run.py`. The monitor observes the top's array-write strobe and records one count per pulse. Store/partial merge and fill kinds are tracked separately. Reads, write-back reads and metadata updates do not count. The testbench records RTL counters at HALT. It does not verify cache behavior; T3.3 and T3.5 do that.

Acceptance command: `scripts/run.sh -- python3 analysis/wear_run.py work/wear_smoke/program.hex work/wear_smoke/run --maxcyc 100000 --expect-exit 1892521041` after `scripts/run.sh -- python3 sw/build.py work/wear_smoke sw/smoke/checksum.c`. Result: compiled with Verilator and HALT matched; `work/wear_smoke/run/{wear_windows.csv,wear_lines.csv,wear_phases.csv,dc_trace.csv,simulation.log}` produced. The checksum smoke program intentionally exits with its checksum, 1892521041. An earlier smoke invocation incorrectly expected zero and failed only that run-script exit check; the simulation itself halted normally. Added an explicit expected-exit argument.

No RTL or protected tests changed. Commit: this task's `T3.1:` commit on `t3-wear` (`git log --format=%H -1`).
