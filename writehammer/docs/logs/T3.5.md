# T3.5 Independent golden cache replay

Goal: replay RTL completed D$ requests through an independently written Python cache model and match every per-line array-write count plus RTL hits, misses, fills and write-backs. A deliberately mis-counting monitor must be rejected.

Created `analysis/wear_replay.py` and `analysis/wear_replay_suite.py`; added `tests/mutants/wear_mutants.py`. The replay uses the pre-existing `tests/cache_model.py`, written before this wear monitor. It reads only the RTL access trace and cache geometry to calculate expected counts. The mutant increments one real monitor CSV line count in a copied run and confirms the replay rejects it. Original run files are untouched.

Commands and results:

- `scripts/run.sh -- python3 analysis/wear_replay.py work/wear_known/mixed/run`: 7 requests, 9 array writes, exact match.
- `scripts/run.sh -- python3 analysis/wear_replay.py work/wear_smoke/run`: 108 requests, 71 array writes, exact match.
- `scripts/run.sh -- python3 tests/mutants/wear_mutants.py work/wear_smoke/run`: mis-counting monitor mutant caught at line 0 (6 versus model 5).
- `scripts/run.sh -- python3 analysis/wear_replay_suite.py --benign`: 13/13 benign workloads passed at primary memory latency 20 cycles, 2 KiB D$, 16-byte lines. Every per-line count and RTL access/hit/miss/fill/write-back/bypass/write counter matched exactly. An exploratory pass at latency 2 also passed 13/13. Per-run raw traces and `replay_result.json` are under `work/wear_suite/`.
- `scripts/run.sh -- scripts/check_locks.sh --add` and `scripts/run.sh -- scripts/check_locks.sh`: the new mutant test is locked; 48 protected files verified.
