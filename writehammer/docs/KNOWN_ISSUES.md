# KNOWN ISSUES

Every known bug, limitation, lint waiver and unverified area (spec 0B.10). Lint waivers are listed with their root cause; blanket waivers are not allowed.

| ID | Kind | Where | Description and root cause | Status |
|---|---|---|---|---|
| KI-001 | lint waiver (`UNUSEDSIGNAL`) | `rtl/icache.sv`, `addr` port | `addr[1:0]` is never used: fetch addresses are word-aligned (RV32I, no compressed instructions). The port stays 32 bits because it carries `PCF` unchanged. | open (permanent unless the C extension is added) |
| KI-002 | lint waiver (`UNUSEDSIGNAL`) | `rtl/dcache.sv`, `addr` port | `addr[1:0]` unused while the D$ handles word accesses only. Byte enables in T2.4 use these bits. | open until T2.4 |
| KI-003 | lint waiver (`UNUSEDSIGNAL`) | `rtl/backing_mem.sv`, `addr` port | Address bits above the array and below the word are unused: addresses wrap, the same as the original `imem`/`dmem`. `backing_mem` is replaced by `mem_model` in T2.1. | open until T2.1 |
| KI-004 | limitation | `rtl/rv32_top_pipelined.sv` Memory stage | Misaligned loads and stores are unsupported: the store lane logic and load extender assume natural alignment (`lh`/`lhu`/`sh` at even addresses, `lw`/`sw` at multiples of 4). No exception is raised; the access silently reads or writes the wrong lanes. The arch-test subset excludes misalignment tests (T1.5). The reference model raises on a misaligned access, so tests never generate one. | open |
| KI-005 | limitation | MMIO window | Only stores are decoded. A load from `0xF000_0xxx` goes to the data memory or D$ and returns whatever is at that wrapped address. Programs must not read MMIO. | open |
| KI-006 | limitation | `tb/sys_monitor.sv` | Counter window boundary: a stall or redirect whose signal is high in or before the START store's Memory cycle is not counted, though its bubbles fall inside the window (at most 2 events per window). Negligible for runs of thousands of cycles; tests avoid it by padding. | open |
| KI-007 | limitation | `rtl/rv32_top_pipelined.sv` memories | Until T2.1 the instruction and data memories are separate, and with `DMEM_FROM_IMAGE=1` each holds a full copy of the linked image. Programs must not write code memory (the linker script keeps code and data on disjoint pages) and stores never become visible to instruction fetch. Replaced by the unified `mem_model` in T2.1. | open until T2.1 |
| KI-008 | lint waiver (`UNUSEDSIGNAL`) | `rtl/rv32_top_pipelined.sv`, `dbg_widx` port | The simulation debug read port is 32 bits wide but only the low `log2(MEM_WORDS)` bits index the memory. Kept 32 bits so testbenches can pass a plain word index for any memory size. | open |
| KI-009 | limitation | `make arch-test` run time | The three-configuration run takes about 61 minutes: `jal-01` is a 1.76 MB image (it exercises +-1 MiB jump offsets) and Icarus simulates its 2 Mi-word memories slowly. It is therefore not part of `make test` or the mutation suite; `tests/arch_mutant_check.py` (about 1 minute) is the fast control. A Verilator build would be much faster (T6.1 uses Verilator for long runs). | open |
| KI-010 | limitation | benchmark rates | Dhrystone/MHz and CoreMark/MHz are unofficial: fixed iteration counts, no clock, simulation, rv32i with software multiply/divide, -O2. They are for comparing configurations in this study, not for publication as benchmark results. | open |
| KI-011 | limitation | `sw/coremark` build | CoreMark needs `-fno-isolate-erroneous-paths-dereference` with GCC 13 (it otherwise emits `ebreak` on a never-executed null-dereference path). The ISA check in `sw/build.py` is unchanged. A different compiler version may not need it. | open |
| KI-012 | limitation | simulators | `INIT_FILE`/`IMEM_FILE` parameters are deliberately untyped: typed `string` parameters work in Verilator but fail to elaborate in Icarus 12 (generate-scope binding), untyped ones work in both. | open |
| KI-013 | lint waiver (`UNUSEDSIGNAL`) | `rtl/mem_model.sv`, `addr_q` | The latched request address is 32 bits but only the bits that index the array (and not the line offset) are used; addresses wrap modulo the memory size by design. | open |
| KI-014 | lint waiver (`UNUSEDSIGNAL`) | `rtl/dcache.sv`, `addr` and `peek_addr` ports | Bits `[1:0]` are unused: accesses are word-granular at this interface, and the byte lanes come from the byte enables. | open |
| KI-015 | lint waiver (`UNUSEDSIGNAL`) | `rtl/write_guard.sv` inputs | `array_write_valid`, `line_idx`, `store_line`, `cycle_strobe` are consumed only by some detectors (NONE, NEVER, ALWAYS, PLACEBO ignore them); the waiver covers the unused combinations. | open |
| KI-017 | unmet acceptance | T4.7 | The binding PMR rule fails 23 of 24 attack variants because benign `crc32` has PMR(all) 127.937 of a possible 128 (DEC-010). Left failing on purpose; `make attacks-validate` exits 1. | open (author decision) |
| KI-018 | stale documentation | `analysis/attack_runner.py` docstring | It still says the attacks "remain absent until the author defines L, T and Rn". They exist and were implemented from the author's papers. Fix when the file is next touched by its owner. | open |
| KI-019 | missing deliverable (resolved) | T6 synthesis | The core-only top was missing; now delivered as `rtl/core_only.sv` (`CORE_ONLY=1` branch of the top), tested by `tests/core_only_test.py`. | resolved 2026-11-04 |
| KI-020 | not run | T5.5 action A2 | Stall-throttle (A2, `K=16`) is not implemented; `WG_ACTION=1` is an elaboration error. A1 (bypass) is complete and verified. | open |
| KI-021 | approximation | calibration vs RTL windows | `analysis/calibrate.py` bins windows as `cycle // WINDOW`; the RTL timer starts at reset and defers a window end past a mid-request store, so RTL windows can differ by a few cycles. Thresholds are therefore not exact per-window maxima of the RTL's windows; false-positive rates are measured on the RTL itself in T6. | open |
| KI-022 | test-design note | `tests/guard_mutants.py` X1/X2 | The invariant-breaking bypass mutants are caught because the broken core hangs (TIMEOUT at the 150M-cycle cap), not by a subtle signature difference; slow but a valid catch. | open |
| KI-023 | test robustness | `tests/guard_mutants.py` G17 | In the final run G17 (window ignores freeze) was caught by a Verilator internal build error in a parallel build, not by a behavioral mismatch; the earlier run caught it by a cycle mismatch (rand_0_burst). Valid but the weaker kind of catch; rerun `tests/guard_mutants.py` alone if in doubt. | open |
